# kuf v0.3.0

## ペインごとのソート

- 名前・拡張子・サイズ・更新日時の昇順／降順に対応しました。操作中のペインだけを変更するので、左右で別々の並び順を使えます。
- 「表示」メニュー、パス横の並び順ボタン、`Ctrl+Shift+S` で選択できます。`Ctrl+Shift+R` で順序を反転します。
- キーマップにも各ソート操作を追加しました。既存のカスタム割り当てを優先します。
- ファイルを読み直さず並べ替え、カーソル・選択・絞り込みを保持します。左右の並び順は前回の状態と作業セットに保存します。
- 更新日時は表示文字列より細かい実時刻で比較します。不明な日時は昇順・降順とも最後です。
- 親フォルダーとフォルダー優先表示は、降順でも先頭を維持します。あいまい絞り込み中は一致度を優先し、同点を指定ソートで並べます。

既存の設定・作業セットは引き続き読み込めます。新しい並び順を保存した作業セットを古いバージョンで開くと、読み込みを拒否する場合があります。保存ファイルを削除せず、新しいバージョンで開いてください。

詳しい操作は [操作性の改善と検証](../usability.md) を参照してください。

## 配布物

- Windows x64: MSI / NSISインストーラー
- macOS Apple Silicon: DMG / app archive
- Linux x64: Debian package / AppImage

macOSはアドホック署名を使用し、開発者証明書による署名・公証は未設定です。macOS/Linuxの実画面操作は未検証です。
