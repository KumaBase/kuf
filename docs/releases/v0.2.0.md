# kuf v0.2.0

## 使いやすさ

- 即時絞り込みを追加。曖昧一致、空白区切りのAND、Migemoによるローマ字からの日本語検索、一致箇所の強調に対応しました。部分一致への切替とワイルドカードも使えます。
- 左右の場所とタブ構成を、作業セットとして保存・復元できます。前回終了時の構成も復元します。
- 表示中のローカルフォルダーの変更を自動で反映します。ファイル処理中は更新を保留し、選択やカーソル位置を維持します。
- ローカルの削除をごみ箱への移動に変更しました。Windowsでは固定ドライブが対象です。SFTPは確認後の完全削除です。
- コピー・移動などの進捗表示と、項目の間での停止に対応しました。
- 大きな一覧での選択・タブ切替を改善し、ローカルI/Oを画面の処理から分離しました。
- メニュー・設定・キーボード操作を整え、新しいくまアイコンを採用しました。

## 更新時の設定

既存のフォント・行高・カスタムキーバインドを保持します。新しい操作の既定キーは既存の割り当てを優先して補完します。

詳しい使い方と検証範囲は [操作性の改善と検証](../usability.md) を参照してください。

## 配布物

- Windows x64: MSI / NSISインストーラー
- macOS Apple Silicon: DMG / app archive
- Linux x64: Debian package / AppImage

macOSはアドホック署名を使用します。開発者証明書による署名・macOS公証は今回の公開設定に含まれていません。macOS/Linuxの実画面操作は未検証です。
