# kuf v0.4.0

あふｗを主な基準、だいなファイラーを補助として、日常の選択・移動・一括処理を補いました。

- Ctrl+Shift+Pでコマンドを検索し、名前から実行できます。新機能はメニューとキーマップからも利用できます。
- Shiftによる範囲選択、Shift+Spaceでの上方向マーク、ワイルドカード選択、ファイル/フォルダ別選択を追加しました。
- Hで履歴一覧から移動できます。親へ戻ると直前の子フォルダにカーソルを戻し、履歴でも名前で復元します。
- Wで相手にない・異なる・新しいファイルを選択できます。表示中の一覧にあるサイズと日時を比較します。
- Shift+Rで置換・接頭/接尾・連番の一括リネームをプレビューできます。既存先への上書きは拒否します。
- Shift+Fでローカルのサブフォルダを含む名前を検索し、結果から場所へ移動できます。途中停止と件数上限に対応します。
- P/UでZIPを作成・展開できます。作成先は新規のファイル/フォルダに限定し、元のファイルを保持します。
- Shift+Xで外部ツールを登録し、選択パスや左右のフォルダを別々の引数として渡せます。
- プレビューをUTF-8/Shift-JIS/EUC-JP/UTF-16、文中検索、バイナリ表示へ拡張しました。SFTPとホーム外の画像にも対応しました。
- O/Shift+Oの説明を実動作に揃え、同じ場所でのカーソル同期を追加しました。ファイルのダブルクリック、複数の名前コピー、設定保存失敗の表示、キー解除の保存も改善しました。

操作と比較結果、対象範囲は[あふｗ・だいなファイラーとの比較](../filer-comparison.md)にまとめています。配下検索・一括リネーム・ZIP・外部コマンドはローカル対象です。途中停止・失敗したZIPの作成途中データは場所を表示して保持します。

配布物: Windows x64（EXE/MSI）、macOS Apple Silicon（DMG/app archive）、Linux x64（deb/AppImage）。macOSはアドホック署名で、開発者証明書による署名・公証は未設定です。
