# kuf v0.2.1

## 起動時の表示

Windowsで起動直後に白い画面が見える現象を抑えました。ウィンドウ・WebViewと、スタイルシートを読み込む前のHTMLに、アプリの既定テーマと同じ背景色を指定しています。

初期画面が表示されるまでの背景の改善です。検索・ファイル操作・保存済みの設定や作業セットの動作は変更していません。

v0.2.0で追加した機能は [v0.2.0のリリースノート](v0.2.0.md) を参照してください。

## 配布物

- Windows x64: MSI / NSISインストーラー
- macOS Apple Silicon: DMG / app archive
- Linux x64: Debian package / AppImage

macOSはアドホック署名を使用します。開発者証明書による署名・macOS公証は今回の公開設定に含まれていません。Windowsでは起動を確認し、macOS/Linuxの実画面操作は未検証です。
