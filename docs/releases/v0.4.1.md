# kuf v0.4.1

- macOS版アプリをDeveloper IDで署名し、Appleの公証を受けた状態で配布します。
- SFTP接続時、認証情報を送る前にサーバーのホスト鍵を確認します。初めて接続する場合は、表示されるフィンガープリントをサーバーの管理者に別の連絡手段で確認してから承認してください。
- 登録済みのホスト鍵が変わった場合は接続を拒否します。ホスト鍵の変更が正当なものか、管理者に確認してください。
- SFTP接続は `~/.ssh/known_hosts` を使用します。SSHの証明書認証局や別のknown_hostsファイルの指定には対応していません。

配布物: Windows x64（EXE/MSI）、macOS Apple Silicon（DMG/app archive）、Linux x64（deb/AppImage）。
