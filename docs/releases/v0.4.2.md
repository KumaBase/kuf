# kuf v0.4.2

- クリック後にCtrl（MacではCommand）を押して別の項目を選ぶと、最初の項目も選択に残るようにしました。Shiftクリックの範囲選択にも対応します。
- ローカルの項目を一覧やフォルダーへドラッグしてコピーできます。Shiftを押してドロップすると移動でき、対象・コピー先や既存ファイルの上書きを確認します。確認後に同名項目が作成された場合も、承認なく置き換えません。SFTPとの転送はF5/F6を利用してください。
- WindowsのExplorerやmacOSのFinderから、ファイル・フォルダーをkufへドロップしてコピーできます。kufから外部アプリへのドラッグは未対応です。
- 一覧の空白部分にも右クリックメニューを表示し、kuf内のコピー・切り取り・貼り付けや一覧更新をマウスで操作できます。右クリックしたフォルダーへの貼り付けもできます。
- メニューを画面内に収めてスクロール可能にし、開いている間に一覧が変わった場合は対象を選び直せるようにしました。Macなどで名前にバックスラッシュを含むフォルダーの移動も修正しました。

操作方法と対象範囲は[操作ガイド](../usability.md)をご覧ください。Windows実画面でクリック、右クリック、スクロール、フォルダーを開く操作と、隔離したテストファイルのドラッグコピーを確認しました。Explorer/Finderとの実際のドラッグ、およびMacの実画面操作は未検証です。

配布物: Windows x64（EXE/MSI）、macOS Apple Silicon（DMG/app archive）、Linux x64（deb/AppImage）。
