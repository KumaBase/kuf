# あふｗ・だいなファイラーを参考にした操作の改善

調査日: 2026-10-25。あふｗを主な基準とし、だいなファイラーの公式情報も補助として照合しました。kuf v0.4.0では、選ぶ・移動する・左右を比較する・まとめて処理する操作を補いました。

## 参照した一次資料

- [あふｗ公式配布ページ](https://afxw.sakura.ne.jp/akt_afxw.html)と[公式v1.67配布ZIP](https://afxw.sakura.ne.jp/lzh/afxw64_167.zip)同梱の `AFXW.TXT`、`AFXWCFG.TXT`、`AFXWKEY.TXT`。マーク、履歴、O/Shift+O、比較マーク、拡張改名、再帰検索、外部コマンドの説明を確認しました。配布物は資料を読むために用い、実行していません。
- [だいなファイラー作者公式ページ](https://dynaprj.bitbucket.io/vector/dyna.html)と[Microsoft Store掲載](https://apps.microsoft.com/detail/9p6mwcbsqfkk?hl=ja-JP&gl=JP)。フルキーカスタマイズ、Migemo、MarkBelow群、検索条件の履歴、外部コマンドのマクロ、日本語・バイナリ・画像ビューアーを確認しました。同梱ヘルプは取得できなかったため、公式ページにない細部を搭載済みとは推定していません。

## 日常操作

1. Fで一覧を絞るか、Shift+Fで配下の名前を探します。検索結果でEnterを押すと、そのファイルの親フォルダに移動してカーソルを合わせます。
2. Space/Shift+Space、Shift+矢印、@を使って対象を選びます。選択件数とファイルの合計サイズを下部で確認できます。
3. Wで左右を比較し、相手にないファイルなどを選択します。比較対象は現在表示中のファイルで、フォルダ内の再帰比較や内容の一致判定ではありません。コピーするときは続けてC/F5を使います。
4. Shift+Rで変更後の名前を確認してから一括変更します。既存先へは上書きしません。入れ替えや循環する改名は拒否します。停止・失敗時には変更済みと未完了の件数を示します。
5. Pで選択項目を現在地の新しいZIPにまとめ、UでカーソルのZIPを相手ペイン内の新しい子フォルダへ展開します。停止・失敗時の途中成果は、エラーに表示する場所へ残ります。

## 外部コマンド

Shift+Xから名前・実行ファイル・引数を登録します。引数は1行につき1個で、空白を含むパスを引用符で囲む必要はありません。空行は空の引数を表します。空文字の引数を1個だけ渡す場合は、専用のチェックを使います。外部コマンドは通常の実行ファイルが対象で、シェル（cmd/PowerShell等）やbat/cmdの実行は未対応です。

| 記法 | 渡す値 |
|---|---|
| `{file}` | カーソル項目のフルパス |
| `{name}` | カーソル項目の名前 |
| `{dir}` | 現在のフォルダ |
| `{other}` | 相手ペインのフォルダ |
| `{selected}` | 選択パスをそれぞれ別の引数にする（独立した1行で指定）。未選択時はカーソル項目 |

例えばエディタの実行ファイルを指定し、引数に `{selected}` を1行登録すれば、選択した複数ファイルを渡せます。比較ツールなら `{dir}` と `{other}` を別々の行に置けます。実行内容は画面で確認でき、Ctrl+Enterで保存して起動します。通常の実行ファイルへ直接引数を渡します。端末で対話する作業には既存の「ターミナルを開く」を使います。

## 検証

ローカルのTypeScript検査、フロントエンド62件、WindowsのRust78件が成功しました。既存の明示実行用3件はスキップしています。Rustでは生成データだけを使い、検索の停止・読取失敗、ZIPの往復・衝突・破損、一括改名の競合・部分完了、設定の原本保持を確認しました。

Chrome上に本物のAppと隔離したAPI fixtureを表示し、範囲選択、パレットからの実行、履歴復帰、比較、一括改名の事前表示と取消、ZIPの確定・取消、外部ツール引数、日本語・バイナリ・画像プレビュー、検索結果への移動を確認しました。設定の保存失敗、キーの再割り当て、モーダル中の別操作拒否、640×480での操作も確認しています。外部プログラムはfixtureで置き換えており、ユーザーのアプリや設定には触れていません。

実SFTPサーバーとの通信、Tauriネイティブの実画面操作、OSの関連アプリ起動は未検証です。ブラウザの表示確認と実機・実通信の確認は区別しています。

## 制約と今後の差分

- 配下検索、一括リネーム、ZIP、外部コマンドはローカル対象です。SFTPは従来の転送・単件改名・削除と、新しいプレビューに対応します。
- 検索はシンボリックリンク先を辿りません。最大結果5,000件、確認項目100万件、深さ128で停止し、上限や読めない項目を画面へ表示します。
- ZIPは通常ファイルとフォルダが対象です。暗号化・リンク・特殊ファイル・パス逸脱・衝突を拒否します。上限は10万項目、単一8 GiB、合計20 GiB、深さ64、管理情報128 MiBです。
- プレビューはテキスト/バイナリ2 MiB、画像20 MiBまでです。自動文字コード判定は推定なので、表示が違う場合は手動で切り替えます。hexは16 KiB単位、文中検索の表示は最大2,000箇所です。
- 参考ソフトの全互換には至っていません。書庫を仮想フォルダとして開く操作、7z/RAR等、再帰的な内容検索、属性・日時変更、ファイル操作のUndo、Windows専用のMTP/Susie/IPreviewHandler/DLL連携は未実装です。次の機能単位として独立して扱います。
- 新機能は既存のカスタムキーを優先します。表のキーと動作が異なる場合は、Ctrl+Shift+Pまたは設定のキーマップで実際の割り当てを確認してください。
